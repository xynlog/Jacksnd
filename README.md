# 视频重创工作台 v0.2.18

这是本地运行的“原片拆解 → 创意工坊 → 组合成片”工作台。第一次使用请阅读 [先读我_启动与使用.md](先读我_启动与使用.md)，Windows 用户直接双击 `启动工作台.bat`。

主要入口：

- `启动工作台.bat`：自动准备环境并打开工作台；
- `安装工作台.bat`：只安装环境；
- `安装_语音识别.bat`：可选安装本地 faster-whisper；
- `检查环境.bat`：检查 Python、Pillow、FFmpeg 和可选语音识别；
- `docs/API_适配与素材分配.md`：API 能力、提示词与参考素材的实际映射；
- `docs/开发与验证.md`：测试范围、运行命令和真实 API 验收边界。
- `docs/项目立项_需求决策与完整变更记录_2026-09-09.md`：从 Video Insight Studio 立项、v0.1.x 到当前版本的全部需求决策、实机问题、版本变更、当前能力和待办总档案。

v0.2.14 修复产品编辑窗口缺失“商品 Listing 文案”区域的问题，并保留 v0.2.12 的素材图片多选删除功能。产品卡片的“生成 Listing”按钮旁现在显示 Listing API；只有一个可用画面理解 API 时会自动选择，快捷入口和产品编辑窗口均可正常提交。具体说明见 `docs/v0.2.14_Listing入口与API自动选择修复.md`。

v0.2.15 允许只根据产品参考图直接生成 Listing，不再强制填写卖点或参数。图片超过 API 上限时，系统会优先保留主图并均匀抽取代表图，不再要求手动删除图片。具体说明见 `docs/v0.2.15_Listing图片直出与超限自动选图.md`。

v0.2.16 自动处理 Listing 模型返回的两类常见格式偏差：中文对照允许保留品牌、型号、SKU、单位及通用英文；英文搜索关键词超过 250 字符时自动按完整关键词边界缩短。旧失败任务可直接“继续 / 重试”，复用已有响应完成校验与保存。具体说明见 `docs/v0.2.16_Listing失败自动修正.md`。

v0.2.18 将生成前检查改为“提醒优先”：资料缺失、Listing 快照缺失或接洽过期只提示、不阻止已确认任务生成；参考图超过模型上限时自动保留背景/人物并均匀抽取产品图。具体说明见 `docs/v0.2.18_生成不中断与参考图自动抽样.md`。

v0.2.12 增加统一的“查看 / 编辑视频任务”工作台：在生成与成片页可一次修改创意稿、卖点接洽、背景/人物/产品参考图、比例、分辨率、宽高、帧率、时长和音轨设置。卖点接洽改为左侧原产品/原视频、右侧新产品的集中对比；产品与人物资料中的图片可勾选批量删除。点击“保存并人工审核通过”后，应用锁定该任务的确切版本并以人工审核为最高权限；自动差异、重复和事实提示不再阻止该版本生成，同一审核版本也可以主动重复生成。具体说明见 `docs/v0.2.12_统一任务编辑与人工审核.md`。

v0.2.13 修复统一任务编辑页“保存修改 / 保存并人工审核通过”被缺失的接洽程度字段拦截的问题。统一页现在明确显示高/中/低接洽程度，旧任务缺失时自动补为“中”；保存和审核按钮会显示执行状态，失败信息会自动滚动到可见区域并弹出提示。具体说明见 `docs/v0.2.13_任务保存与审核按钮修复.md`。

v0.2.11 将人工确认的卖点接洽设为创意内容的最终放行依据。只要当前接洽方案已经确认，模型返回的创意差异、相似度、事实疑点、品类差异、表达偏差和历史复核失败一律只记录、不阻断，也不再额外调用一次独立复核 API。程序仅保留生成视频必需的 JSON、返回数量、提示词和连续分镜时间轴校验。具体说明见 `docs/v0.2.11_确认接洽后直接生成.md`。

v0.2.10 将卖点接洽改为“结构迁移优先”：原产品与新产品的名称、品牌、型号、SKU、品类差异属于正常换品，不参与冲突判断；高、中、低三种接洽程度均可继续。程序只迁移原片的 Hook、说服结构、卖点顺序、证明方式、节奏和 CTA 作用，再用新产品的确认事实重写内容。误填到禁止宣传承诺中的产品名称或品类会自动忽略。v0.2.11 已进一步取消确认后的内容复核阻断。具体说明见 `docs/v0.2.10_结构迁移与产品身份放行.md`。

v0.2.9 增加商品 Listing 工作流：产品资料页可用已配置的画面理解 API 一键生成英文 Listing、中文对照、250 字符以内搜索关键词、5 条卖点、5 条一句话亮点，并把图片参考集中保存。英文与中文可分别在线编辑、保存、确认，确认后的 Listing 会自动进入创意工坊的卖点接洽依据；未确认或产品资料变化时不会被创意任务静默使用。具体说明见 `docs/v0.2.9_商品Listing与资料接洽.md`。

v0.2.7 新增独立云端语音识别通道：`qwen-audio-3.0-asr-flash` 不再误填到画面模型，而是通过百炼原生 ASR 接口接收从视频提取的 16 kHz 音频。画面、语音、文字、图片和视频分别路由；转写分段保存并可断点续跑，时间轴可在应用内逐段修改。具体说明见 `docs/v0.2.7_云端语音识别与配置.md`。

v0.2.6 修复 API 连接测试中的 `json_object` 漏导入错误和失败拆解使用当前配置重试的问题，说明见 `docs/v0.2.6_API配置与重试修复.md`。

v0.2.5 已修复新设备首次安装：限定 winget 源、等待 Python 安装进程结束并读取该进程的结果、实际检查运行环境、保留实时安装日志。新设备只需完整解压后双击 `启动工作台.bat`；已安装成功的老设备可以继续使用。

密钥只存于本机凭据存储，不写入项目库、备份或任务包；换设备后需重新填写。真实服务商的模型开通、配额、价格和生成质量以账号实际返回为准。
